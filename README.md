# Belajar jQuery - Coding Studio

Repository ini berisi kumpulan latihan dasar penggunaan **jQuery** untuk manipulasi DOM, penanganan event, serta efek animasi (seperti show, hide, fadeIn, fadeOut, dan slideToggle) guna mempermudah penulisan kode JavaScript.

## Fitur / Materi yang Dipelajari:
- DOM Selection & Manipulation (`.html()`, `.attr()`, `.css()`, dll.)
- Event Handling (Click, MouseEnter, dll.)
- Efek Animasi & Transisi jQuery

## Teknologi yang Digunakan:
- HTML5
- JavaScript (jQuery Library)
